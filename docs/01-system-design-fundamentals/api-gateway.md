## 📖 Deep Dive Notes

### 1. সহজ সংজ্ঞা ও Intuitive Mental Model

একটি মাইক্রোসার্ভিস আর্কিটেকচারে ক্লায়েন্ট (ওয়েব, মোবাইল, থার্ড-পার্টি অ্যাপ) এবং অভ্যন্তরীণ শত শত ব্যাকএন্ড সার্ভিসের মধ্যে অবস্থিত একক এন্ট্রি পয়েন্ট বা মধ্যবর্তী ইন্টেলিজেন্ট রিভার্স প্রক্সিকে **API Gateway** বলে।

```
                       [ External Clients ]
                    (Web, Mobile, 3rd Party)
                               │
                               ▼
                   ┌───────────────────────┐
                   │      API GATEWAY      │
                   │ ───────────────────── │
                   │ • SSL Termination     │
                   │ • Auth & Token Verify │
                   │ • Rate Limiting & WAF │
                   │ • Request Routing     │
                   │ • Metrics & Tracing   │
                   └───────────┬───────────┘
                               │
            ┌──────────────────┼──────────────────┐
            ▼                  ▼                  ▼
      [ User Service ]   [ Order Service ]  [ Payment Svc ]
```

> 🧠 **Intuitive Mental Model (আন্তর্জাতিক বিমানবন্দরের ইমিগ্রেশন ও কাস্টমস):**
> আপনি বিদেশ থেকে একটি দেশে প্রবেশ করছেন। 
> বিমানবন্দরটিতে সরাসরি কোনো ট্যাক্সি বা ট্রেনে উঠে দেশের ভেতরে চলে যেতে দেওয়া হয় না। সবাইকে একটি কেন্দ্রীয় আন্তর্জাতিক টার্মিনাল দিয়ে প্রবেশ করতে হয় (**Single Entry Point**)। 
> সেখানে ইমিগ্রেশন অফিসার আপনার পাসপোর্ট ও ভিসা চেক করেন (**Authentication/JWT**), কাস্টমস স্ক্যানার আপনার ব্যাগ স্ক্যান করে ক্ষতিকর জিনিসপত্র আটকায় (**WAF/Security**), অতিরিক্ত ভিড় হলে লাইনে দাঁড় করায় (**Rate Limiting**), এবং ক্লিয়ারেন্স পাওয়ার পর আপনাকে কোন প্ল্যাটফর্মের ট্রেনে যেতে হবে তার দিকনির্দেশনা দেয় (**Routing/Reverse Proxy**)। 
> এয়ারপোর্টের টার্মিনাল না থাকলে সারা দেশে বিশৃঙ্খলা ও চরম নিরাপত্তা ঝুঁকি তৈরি হতো!

### 2. API Gateway-এর কোর দায়িত্বসমূহ (Core Responsibilities)

1. **Authentication & Authorization:** ক্লায়েন্টের JWT টোকেন বা API Key ভ্যালিডেট করে। ইনভ্যালিড টোকেন হলে গেটওয়ে থেকেই `401 Unauthorized` বা `403 Forbidden` ফেরত দেয়, ফলে ব্যাকএন্ড মাইক্রোসার্ভিস পর্যন্ত অযথা ট্রাফিক যায় না।
2. **Dynamic Rate Limiting:** ইউজার বা আইপি ভিত্তিক ট্রাফিক নিয়ন্ত্রণ করে ডিস্ট্রিবিউটেড DoS আক্রমণ এবং সিস্টেম স্যাচুরেশন প্রতিরোধ করে (`429 Too Many Requests`)।
3. **Request Routing & Path Rewriting:** `/api/v1/users/*` কে User Service-এ এবং `/api/v1/orders/*` কে Order Service-এ রাউট করে।
4. **SSL/TLS Termination:** ইন্টারনেট থেকে আসা HTTPS ট্রাফিকের এনক্রিপশন ডিক্রিপ্ট করে অভ্যন্তরীণ সার্ভিসে দ্রুত ও হালকা HTTP/2 বা gRPC-তে পাঠায়।
5. **Protocol Translation:** এক্সটার্নাল ক্লায়েন্টের জন্য REST/JSON ইন্টারফেস প্রদান করে কিন্তু ইন্টারনাল সার্ভিসের সাথে উচ্চগতির gRPC বা প্রোটোকল বাফার্সে যোগাযোগ করে।
6. **API Aggregation / Composition:** একটি মোবাইল স্ক্রিনের জন্য User Service, Notification Service এবং Order Service থেকে ৩টি কল করে একটি মার্জ করা JSON রেসপন্স রিটার্ন করে।

### 3. Backend-for-Frontend (BFF) Pattern

```
                       [ Web App ]         [ Mobile App ]
                            │                    │
                            ▼                    ▼
                    ┌──────────────┐     ┌──────────────┐
                    │ Web BFF GW   │     │ Mobile BFF GW│  <-- BFF Layer
                    └───────┬──────┘     └───────┬──────┘
                            │                    │
                            └─────────┬──────────┘
                                      ▼
                        [ Internal Microservices ]
```

- সাধারণ সিঙ্গেল গেটওয়েতে একটি সমস্যা দেখা যায়: মোবাইল অ্যাপ চায় কম ব্যান্ডউইথ ও ছোট JSON পে-লোড, অন্যদিকে ওয়েব ড্যাশবোর্ড চায় বিস্তারিত ডেটা।
- **BFF প্যাটার্ন** অনুযায়ী ওয়েব, মোবাইল এবং থার্ড-পার্টি পার্টনারদের জন্য আলাদা আলাদা অপটিমাইজড গেটওয়ে রাখা হয়।

### 4. Alternatives & Technologies Comparison Matrix

| টেকনোলজি | ইঞ্জিন / ভাষা | থ্রুপুট ও ল্যাটেন্সি | এক্সটেনসিবিলিটি | কনফিগারেশন মডেল |
|---|---|---|---|---|
| **Kong Gateway** | Nginx + OpenResty (Lua) | অত্যন্ত উচ্চ (মাইক্রোসেকেন্ড) | প্লাগইন (Lua, Go, JS) | ডেটাবেজ-লেস (YAML) বা PG |
| **Envoy Proxy** | C++ | সর্বোচ্চ (আল্ট্রা লো-ল্যাটেন্সি) | Wasm (WebAssembly), C++ | ডাইনামিক gRPC xDS API |
| **AWS API Gateway** | Managed Serverless | মাঝারি (ল্যাটেন্সি সামান্য বেশি) | Lambda ও CloudWatch | AWS Console / IaC |
| **KrakenD** | Go | চরম দ্রুত (নো-মেমোরি স্টেট) | Go Plugins | ডিক্লেয়ারেটিভ JSON/YAML |
| **Spring Cloud Gateway** | Java (Netty Reactive) | মাঝারি | Java Filters | Spring Boot Annotations |

### 5. Failure Modes & Bottlenecks

#### Failure Mode 1: Single Point of Failure (SPOF) & Blast Radius
- **ঝুঁকি:** গেটওয়ে ক্র্যাশ করলে পুরো কোম্পানির সমস্ত ওয়েব ও মোবাইল অ্যাপ অকেজো হয়ে পড়ে।
- **প্রতিরোধ (Mitigation):** গেটওয়ের সামনে একটি হাই-অ্যাভেইলেবল L4 লোড ব্যালেন্সার (AWS NLB) রাখা এবং গেটওয়েকে সম্পূর্ণ স্ট্যাটলেস হিসেবে একাধিক অ্যাভেইলেবিলিটি জোনে অটো-স্কেলিং গ্রুপে চালানো।

#### Failure Mode 2: The "Fat Gateway" Anti-Pattern
- **ঝুঁকি:** ডেভেলপাররা গেটওয়ের ভেতরে কোর বিজনেস লজিক, ডাটাবেজ কুয়েরি এবং জটিল ট্রান্সফরমেশন লিখতে শুরু করে। ফলে গেটওয়ে সিপিইউ-স্যাচুরেটেড হয়ে মারাত্মক ল্যাটেন্সি বটলনেক তৈরি করে।
- **প্রতিরোধ:** গেটওয়েকে শুধুমাত্র নেটওয়ার্কিং, সিকিউরিটি এবং রাউটিং কনসার্নে সীমাবদ্ধ রাখা; কোনো বিজনেস ডোমেইন লজিক গেটওয়েতে লেখা নিষিদ্ধ করা।

### 6. Senior / Staff Engineer Interview Defense

> **ইন্টারভিউয়ার:** *"আমাদের সিস্টেমে সার্ভিস মেশ (Service Mesh - Istio) আছে। আমাদের কি তবুও একটি API Gateway প্রয়োজন?"*
>
> 💡 **Staff-Level উত্তরের কাঠামো:**
> "হ্যাঁ, সার্ভিস মেশ এবং এপিআই গেটওয়ে একই আর্কিটেকচারে সম্পূর্ণ দুটি ভিন্ন দায়িত্ব পালন করে এবং তারা একে অপরের পরিপূরক (Complementary):
> 1. **East-West বনাম North-South ট্রাফিক:** API Gateway পরিচালনা করে **North-South ট্রাফিক** (বাইরের পাবলিক ইন্টারনেট থেকে অভ্যন্তরীণ ক্লাস্টারে ট্রাফিক প্রবেশ); আর Service Mesh পরিচালনা করে **East-West ট্রাফিক** (ক্লাস্টারের অভ্যন্তরীণ এক মাইক্রোসার্ভিস থেকে অন্য মাইক্রোসার্ভিসের মধ্যকার যোগাযোগ)।
> 2. **এক্সটার্নাল সিকিউরিটি ও বিজনেসের প্রয়োজন:** বাইরের ক্লায়েন্টদের জন্য এপিআই কী, রেট লিমিটিং, আইপি ব্ল্যাকলিস্টিং, ওআউথ (OAuth 2.0) এবং এপিআই মনিটাইজেশন/বিলিং হ্যান্ডেল করা গেটওয়ের কাজ—যা সার্ভিস মেশ করে না।
> 3. **ইন্টারনাল পলিসি:** সার্ভিস মেশ ইন্টারনাল সার্ভিসগুলোর মধ্যে mTLS এনক্রিপশন, সার্ভিস ডিসকভারি, ডিস্ট্রিবিউটেড ট্রেসিং এবং ইন্টারনাল ফল্ট ইনজেকশন নিশ্চিত করে। তাই এন্টারপ্রাইজ সিস্টেমে গেটওয়ে বর্ডারে থাকে এবং ভেতরে সার্ভিস মেশ থাকে।"

## 📝 Practice Questions

```markdown
### Basic Practice Questions
1. API Gateway কী এবং মাইক্রোসার্ভিসে এর মূল উদ্দেশ্য কী?
2. API Gateway কীভাবে ব্যাকএন্ড সার্ভিসের সিকিউরিটি বৃদ্ধি করে?
3. SSL Termination বলতে কী বোঝায় এবং গেটওয়েতে এটি করার সুবিধা কী?
4. API Gateway এবং Reverse Proxy-র মধ্যকার মৌলিক পার্থক্য কী?
5. একটি গেটওয়েতে রেট লিমিটিং ব্যর্থ হলে ক্লায়েন্ট কী HTTP রেসপন্স পায়?

### Intermediate Practice Questions
6. Backend-for-Frontend (BFF) প্যাটার্ন কী এবং কেন এটি বড় প্রতিষ্ঠানে প্রয়োগ করা হয়?
7. API Gateway কীভাবে একাধিক মাইক্রোসার্ভিসের কল অ্যাগ্রিগেট (Request Aggregation) করে মোবাইল অ্যাপের ব্যাটারি ও ব্যান্ডউইথ সাশ্রয় করে?
8. "Fat Gateway" অ্যান্টি-প্যাটার্ন কী এবং কীভাবে এটি সিস্টেমের পারফরম্যান্স ধসিয়ে দেয়?
9. ডিস্ট্রিবিউটেড মাইক্রোসার্ভিস ক্লাস্টারে API Gateway কীভাবে সার্ভিস ডিসকভারি (Consul/Eureka) এবং ডাইনামিক রাউটিং হ্যান্ডেল করে?
10. গেটওয়ে লেভেলে JWT টোকেন ভ্যালিডেশনের পর কীভাবে ব্যাকএন্ড সার্ভিসে ইউজারের পরিচিতি নিরাপদভাবে পাস করা যায় (Internal Header Injection)?

### Advanced / Staff-Level Questions
11. API Gateway বনাম Service Mesh (Envoy/Istio): এন্টারপ্রাইজ ট্রাফিক ডিজাইনে North-South ট্রাফিক এবং East-West ট্রাফিকের বাউন্ডারি কীভাবে নির্ধারণ করবেন?
12. কোটি কোটি RPS ট্রাফিক হ্যান্ডেল করার সময় API Gateway ক্লাস্টারের সিপিইউ বাফার স্যাচুরেশন ও মেমোরি কনজিউমিং প্লাগইন রোধে WebAssembly (Wasm) আর্কিটেকচার কীভাবে সাহায্য করে?
13. API Gateway-এর মাধ্যমে ব্লু-গ্রিন, ক্যানারি (Canary Routing) এবং শ্যাডো ট্রাফিক (Traffic Shadowing / Dark Traffic) কীভাবে পরিচালনা করবেন?
14. যদি API Gateway কোনো কারণে ডাউন হয়ে যায়, তবে গ্লোবাল Anycast DNS এবং ক্লাউড এজ ফ্রন্ট ডোর (Cloudflare/CloudFront) ব্যবহার করে ডিজাস্টার রিকভারি কীভাবে করবেন?
15. GraphQL Gateway (Federation / Apollo Gateway) ব্যবহার করার সময় মাইক্রোসার্ভিসগুলোর সাব-গ্রাফ রেজোলিউশনের ল্যাটেন্সি ওভারহেড এবং সিকিউরিটি অডিট কীভাবে ডিজাইন করবেন?
```

## 🔑 Answer Key & Self-Test Evaluation

<details>
<summary>👉 <b>Answer Key ও সমাধান দেখতে এখানে ক্লিক করুন</b></summary>

1. **সংজ্ঞা:** মাইক্রোসার্ভিসের একক এন্ট্রি পয়েন্ট যা ক্লায়েন্টের রিকোয়েস্ট গ্রহণ করে রাউটিং, অথেন্টিকেশন ও পলিসি এনফোর্সমেন্ট করে ব্যাকএন্ডে পাঠায়।
2. **সিকিউরিটি বৃদ্ধি:** অভ্যন্তরীণ সার্ভিসের সরাসরি পাবলিক আইপি লুকিয়ে রাখে (Internal Network Isolation) এবং এক্সটার্নাল থ্রেট/DDoS গেটওয়েতেই ব্লক করে।
3. **SSL Termination:** গেটওয়েতেই HTTPS ডিক্রিপ্ট করা। ফলে অভ্যন্তরীণ মাইক্রোসার্ভিসগুলোকে ভারী SSL হ্যান্ডশেকের সিপিইউ ওভারহেড পোহাতে হয় না।
4. **Gateway vs Proxy:** রিভার্স প্রক্সি কেবল রিকোয়েস্ট ফরওয়ার্ড ও ক্যাশিং করে; গেটওয়েতে উন্নত বিজনেস ফিল্টারিং, অথেন্টিকেশন, প্রোটোকল কনভার্সন ও মেট্রিক্স কালেকশন থাকে।
5. **রেট লিমিট এরর:** `HTTP 429 Too Many Requests` সাথে `Retry-After` হেডার।
6. **BFF Pattern:** ক্লায়েন্টের প্রকৃতিভেদে (iOS, Android, Web) ভিন্ন ভিন্ন অপটিমাইজড লাইটওয়েট গেটওয়ে রাখা যা ক্লায়েন্টের নির্দিষ্ট প্রয়োজনমাফিক ডেটা পাঠায়।
7. **Request Aggregation:** মোবাইল অ্যাপ ১টি কল করে গেটওয়েতে; গেটওয়ে ইন্টারনাল হাই-স্পিড নেটওয়ার্কে প্যারালালে ৫টি মাইক্রোসার্ভিসে কল করে একটি সিঙ্গেল কম্প্যাক্ট JSON রেসপন্স পাঠায়।
8. **Fat Gateway:** গেটওয়ের ভেতর অতিরিক্ত বিজনেস লজিক লেখা, যা গেটওয়েকে ধীর করে এবং এটিকে একটি বিশাল ডিস্ট্রিবিউটেড মনোলিথে পরিণত করে।
9. **Dynamic Routing:** গেটওয়ে কনসাল বা কুবারনেটিস এপিআই ওয়াচ করে সার্ভিসের নতুন পড আইপি ডাইনামিকালি তার রাউটিং টেবিলে আপডেট করে নেয়।
10. **Header Injection:** গেটওয়ে ক্রিপ্টোগ্রাফিক JWT ডিকোড করে অভ্যন্তরীণ রিকোয়েস্টে `X-User-Id` এবং `X-User-Roles` হেডার যুক্ত করে দেয়, ফলে ইন্টারনাল সার্ভিসকে আর টোকেন ডিকোড করতে হয় না।
11. **North-South vs East-West:** ইন্টারনেট থেকে ক্লাস্টারে প্রবেশ হলো North-South (API Gateway); ক্লাস্টারের ভেতরে পড-টু-পড যোগাযোগ হলো East-West (Service Mesh)।
12. **Wasm Plugins:** সি++, রাস্ট বা গো-তে লেখা অপটিমাইজড বাইনারি কোড সরাসরি Envoy/Kong গেটওয়ে মেমোরি স্পেসে রান করে, যা ইন্টারপ্রেটেড ভাষার (যেমন Lua) সিপিইউ ওভারহেড নাটকীয়ভাবে কমায়।
13. **Canary & Shadow:** হেডারের ভিত্তিতে (যেমন `X-Beta-User: true`) ট্রাফিকের ৫% নতুন সার্ভিসে পাঠানো; শ্যাডো ট্রাফিকে প্রোডাকশন রিকোয়েস্ট কপি করে টেস্ট সার্ভিসে পাঠানো হয় রেসপন্স ইগনোর করে লাইভ লোড টেস্ট করার জন্য।
14. **Disaster Recovery:** ক্লাউডফ্লেয়ার বা ক্লাউড এজ লেয়ারে ড্রেনিং রুল চালু করা, যা ট্রাফিককে সেকেন্ডারি ক্লাউড রিজিয়নের গেটওয়েতে Anycast দিয়ে ঘুরিয়ে দেয়।
15. **GraphQL Federation:** সাবগ্রাফগুলোর স্কিমা স্ট্যাটিকালি কম্পোজ করা, এনপ্লাস-ওয়ান কুয়েরি রোধে ডেটালোডার ব্যবহার করা এবং ক্লায়েন্টকে ডেপথ লিমিট দিয়ে আটকে ফিল্ড-লেভেল অথেনটিকেশন এনফোর্স করা।
